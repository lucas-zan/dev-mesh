# 安装结束时启动 Worker

- **Status**: 验证成功
- **Scope**: 安装入口在配置和宿主注册完成后启动本地 Worker。

## 行为

- 交互安装有可用配置时提示是否立即启动，回车默认同意，选择不启动时正常结束。
- Worker 已运行时复用。新启动时等待状态接口可用，超时指向日志。
- 非交互安装可传 `--start-worker`，也可用 `--no-start-worker` 跳过。配置未完成或 Worker 被显式禁用时给出明确结果。
- 启动请求不改变仓库自动认领设置。

## 验证

先验证默认启动、跳过、重复安装、状态失败和非交互参数。用隔离发布包启动真实 Worker，确认状态接口后关闭。
