# Worker 角色设置

- **Status**: 验证成功
- **Scope**: 安装引导和已安装配置中的设备角色。

新安装显式选择一项或多项角色，支持逗号分隔或 `all`。重装复用原角色。`devmesh configure` 修改角色，直接回车保留。Worker 重启后按新的角色匹配手动和自动执行的 Issue。Gitea Token 仍决定仓库与 Issue 的查看权限。

先测试新装保存角色、已装编辑与非法值保留配置，再通过解压发布包验证 CLI。完成后更新使用说明和当前安装。
